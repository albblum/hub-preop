# Fase 5 — fora de âmbito

Itens explicitamente **não** entregues no Passo 5 (escrita v2 + guards v1/v2):

- **UI comité** para editar cláusula individual (workspace editorial por cláusula).
- **Criação de árvore v2** via formulário ou `POST /api/instruments` no Hub (instrumentos v2 nascem por scripts Fase 3).
- **Transições multi-acto** (Regime Fundacional §4.1 — ADR 0012).
- **Grafo normativo** entre instrumentos (ADR 0011).
- **Publicação automática** de `publishedAt` no piloto editorial.
- **Desactivação global** de leitura `idr:HUB-INSTR-*` — aliases e resolução legada permanecem para v1 e leitura DocHUB.

Ver handoff: [`handoff-passo-05.md`](./handoff-passo-05.md).
